# TASK_029: 스트릭 휴일/주말 보너스 정책 도입

> 상태: DONE

## 목표
공휴일 및 주말 등 상대적으로 학습하기 어려운 날에 대한 스트릭 보너스(유동성) 정책을 도입하여 사용자의 학습 동기를 유지하고, UI 상에 '휴식일 보너스'를 시각적으로 제공한다.

## 수행 내역
1.  **내부 API 고도화 (`src/app/api/admin/holidays/route.ts`)**:
    - 한국천문연구원 공공 API 호출 및 데이터 가공 전담.
    - **1개월(30일) 캐싱** 정책 적용 (`revalidate: 2592000`).
    - 관리자용 강제 업데이트(`?force=true`) 기능 지원.
2.  **`src/lib/utills/holiday.ts` 개편**:
    - 모든 조회를 내부 API로 단일화하여 중앙 집중식 캐시 관리.
    - **Promise 캐싱**을 도입하여 `Promise.all` 호출 시 중복 네트워크 요청 방지 최적화.
    - `isWeekend`, `isPublicHoliday`, `isRestDay` 기능 제공.
3.  **스트릭 백엔드 로직 업데이트 (`/api/streak/route.ts`)**:
    - 학습 기록 업데이트 시 누락된 날짜(Gap)들을 전수 검사.
    - 공휴일이거나 주말 유동성 조건(토/일 중 하루만 학습해도 스트릭 유지)을 만족하면 스트릭 유지.
    - 보너스일은 스트릭 숫자를 증가시키지 않음(숫자 동결).
4.  **대시보드 보너스 코인 계산 (`src/app/(main)/page.tsx`)**:
    - 이번 주 날짜 중 학습하지 않았으나 보너스 대상(공휴일 또는 주말 유동성 적용일)인 날짜를 계산(`weeklyCoins`).
    - `StreakCard`에 `weeklyCoins`를 전달하여 시각화.
5.  **UI 반영 (`src/components/home/StreakCard.tsx`)**:
    - 보너스일(공휴일/주말 1일 미학습)에 레트로 스타일의 **슈퍼마리오 코인** 아이콘 노출.
    - `CoinIcon` SVG 컴포넌트 추가 및 애니메이션 적용.
