# TASK_029: 스트릭 휴일/주말 보너스 정책 도입

> 상태: PLAN

## 목표
공휴일 및 주말 등 상대적으로 학습하기 어려운 날에 대한 스트릭 보너스(유동성) 정책을 도입하여 사용자의 학습 동기를 유지하고, UI 상에 '휴식일 보너스'를 시각적으로 제공한다.

## 맥락
- 현재 스트릭은 1일이라도 놓치면 즉시 끊어지는 엄격한 구조.
- 사용자가 공휴일에 쉬더라도 스트릭이 유지되길 원함. 단, 학습하지 않은 날이므로 **스트릭 숫자는 증가하지 않아야 함**.
- 만약 공휴일에 자발적으로 학습했다면, 일반적인 스트릭 증가(+1) 및 시즌 스탬프를 부여함.
- 주말(토, 일)의 경우, 2일 중 **1일만 학습해도 스트릭이 이어지도록** 유동성을 부여. (둘 다 안하면 스트릭이 끊기며, 둘 다 하면 +2 증가).
- 보너스로 인정된 휴식일(학습 안한 공휴일, 또는 1회만 학습한 주말의 반대편 휴식일)에는 주간 학습 현황에 레트로한 **슈퍼마리오 코인** 형태의 이미지를 스탬프 대신 표시.

## 연관 파일
- `src/lib/utills/holiday.ts` (API 최적화 및 로직 분리)
- `src/app/api/streak/route.ts` (스트릭 유지/단절 판단 백엔드 로직)
- `src/app/(main)/page.tsx` (주간 현황 코인 여부 계산)
- `src/components/home/StreakCard.tsx` (마리오 코인 UI 렌더링)

## 구현 계획

### 1. `holiday.ts` 유틸리티 개편
- 기존 `isHoliday`는 주말과 공휴일을 모두 true로 반환함. 이를 분리하여 순수 공휴일만 판단하는 `isPublicHoliday` 함수 신설. 기존 `isHoliday` 호출부는 `isPublicHoliday(date) || isWeekend(date)` 조합으로 교체.
- 한국천문연구원 특일 정보 API 호출 시 Next.js `fetch`의 `revalidate: 86400` (1일 캐싱) 적용. 공휴일 데이터는 일 단위 갱신으로 충분하며, 임시공휴일 고시가 당일 반영되는 수준이면 족함.

### 2. 스트릭 백엔드 로직 (`/api/streak/route.ts`)
스트릭 업데이트 시 (POST 요청), `last_study_date`와 `today` 사이의 누락된 날짜(Gap)들을 검사:
- **Gap 검사 루프**:
  1. Gap 내의 모든 날짜를 순회.
  2. `isPublicHoliday`가 `true`면 보너스 휴일로 인정 (통과).
  3. 주말인 경우 토/일 누락을 주차별로 기록.
  4. 평일인데 공휴일이 아니면 스트릭 즉시 단절.
- **주말 유동성 판단**:
  - 동일한 주말에 토/일 모두 누락된 경우에만 스트릭 단절.
  - 하루만 누락된 경우(gap에 없는 반대편 날짜 = 그날은 학습했다는 의미) 보너스 휴일로 인정되어 스트릭 유지.
- 스트릭이 유지되었다면 `current_streak + 1` 적용 (당일 학습에 대한 카운트만 오름).

### 3. 대시보드 주간 현황 계산 (`page.tsx`)
- 이번 주 월~일의 `weeklyProgress` (학습한 날짜)를 가져온 뒤, `weeklyCoins` (코인 표시할 날짜) 배열을 추가로 계산.
- 조건: "과거 또는 오늘 날짜이면서 `weeklyProgress`에 없는 날" 중,
  - `isPublicHoliday`인 경우 → 코인 지급.
  - 주말(토/일) 중 하루이고, 반대편 주말 날짜가 `weeklyProgress`에 있는 경우 → 코인 지급.
- `<StreakCard />`에 `weeklyCoins` prop 전달.

### 4. UI 렌더링 (`StreakCard.tsx`)
- 주간 학습 현황 영역에 `weeklyCoins` prop 추가.
- `coins[i]` 조건 만족 시 레트로한 도트 스타일의 `CoinIcon`(SVG) 컴포넌트를 황금색 테두리 배경과 함께 렌더링.

## 완료 기준
- [ ] 공휴일 결석 시 스트릭이 유지되며, 해당 일자에 마리오 코인이 표시되는가
- [ ] 주말 이틀 중 하루 결석 시 결석한 주말에 마리오 코인이 표시되는가
- [ ] 주말 이틀 모두 결석 시 다음 학습 시 스트릭이 끊어지는가
- [ ] 자발적으로 휴일에 학습 시 스트릭이 정상 증가(+1)하고 스탬프가 찍히는가
- [ ] 자발적으로 휴일에 학습 시 코인이 표시되지 않는가 (스탬프만 찍혀야 함)
