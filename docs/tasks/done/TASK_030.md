# TASK_030: 학습 완료 후 학습 페이지 재진입 및 자유 이동 지원

> 상태: DONE

## 목표

- 학습(step 1~4)을 모두 완료한 유저가 다시 학습 페이지에 진입할 때, `/study/complete`로 튕겨나가지 않고 학습 페이지에 머물 수 있도록 한다.
- 학습이 완료된 영상에 대해서는 프로그레스바의 모든 스텝(1~4)이 활성화되어, 유저가 자유롭게 각 스텝을 클릭하여 원하는 단계를 다시 학습하고 복습할 수 있도록 한다.

## 맥락

- **현재 상황:** `step4_completed_at`이 존재하면 `/study/complete`로 강제 리다이렉트된다. 또한 `StepProgress` 컴포넌트는 `currentStep`보다 크거나 같은 단계로의 이동을 차단한다.
- **연관 파일:**
    - `src/app/(study)/study/page.tsx`
    - `src/components/steps/StepProgress.tsx`

## 완료 기준

- [x] 이미 학습을 완료한 콘텐츠에 step 파라미터 없이 진입할 때, `/study/complete`로 튕기지 않고 `step=4`로 접속되는가
- [x] 학습 완료된 콘텐츠에서는 프로그레스바 상의 모든 단계(1~4)가 주황색으로 활성화되는가
- [x] 활성화된 프로그레스바 단계를 클릭 시, 제한 없이 해당 스텝으로 URL이 정상 전환(`?step=N`) 및 화면이 전환되는가
- [x] 아직 완료하지 않은 콘텐츠에서는 기존 차단 로직(현재 스텝 이전 단계로만 이동 가능)이 동일하게 유지되는가

## 제약

- 스텝 상태는 URL SearchParams로만 관리 (`?step=N`)
- `getSupabaseBrowser()` 싱글턴 등 기존 코드 컨벤션 준수
