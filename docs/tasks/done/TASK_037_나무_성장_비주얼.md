# TASK_037: 나무 성장 비주얼 적용 및 테스트 페이지 구현

> 상태: DONE

## 목표

- 사용되지 않고 있던 `TreeIcons.tsx`의 4가지 계절별 나무 성장 컴포넌트를 `RingGauge.tsx`에 적용하여 학습 스트릭 일수가 늘어남에 따라 나무가 점진적으로 자라나고 눈이 쌓이는 비주얼을 시각화한다.
- 0일부터 100일까지 스트릭 일수를 직접 입력하거나 조절하여 실시간으로 링 게이지 및 나무 성장 상태를 확인할 수 있는 테스트 페이지를 구현한다.

## 맥락

- **현재 상황:** `TreeIcons.tsx`에 정교한 픽셀 아트 스타일의 나무(봄, 여름, 가을, 겨울) 코드가 정의되어 있으나 실질적으로 화면에 사용되지 못하고 단일 아이콘만 표시되는 상태.
- **연관 파일:**
    - `src/components/home/streak/TreeIcons.tsx` (나무 성장 컴포넌트)
    - `src/components/home/streak/RingGauge.tsx` (성장 트리 적용 대상 컴포넌트)
    - `src/components/home/streak/utils.ts` (계절 및 성장도 계산 로직)
    - `src/app/(main)/streak-test/page.tsx` [NEW] (테스트 시뮬레이터 페이지)

## 완료 기준

- [x] 스트릭 일수에 따라 나무의 이파리, 꽃, 단풍, 눈 쌓임 등이 실시간으로 달라지는가 (1~7일 봄, 8~14일 여름, 15~21일 가을, 22일 이상 겨울)
- [x] 30일 이상의 스트릭 구간에서도 링 게이지 및 겨울나무 성장 비주얼이 유지 및 100일까지 누적되는가
- [x] 겨울철 흰 눈 등이 카드 배경과 겹치지 않고 뚜렷이 보이도록 원형 그라데이션 배경판(봄/여름/가을/겨울 테마 적용)이 정상 작동하는가
- [x] 이번 주 학습 현황판에서 요일(월요일 18px ~ 일요일 30px)에 따라 스탬프 크기가 점진적으로 커지는가
- [x] 스트릭 테스트 페이지(`/streak-test`)에서 슬라이더(Slider) 및 입력창을 통해 0~100일 스트릭에 따른 비주얼 변화를 모의 실험할 수 있는가
- [x] 테스트 페이지가 반응형으로 잘 동작하는가
- [x] `pnpm typecheck` 및 `pnpm lint` 통과 여부
