## 종이의 감각을 웹으로: WorksheetRenderer

teding의 핵심 경험은 Step 3, **'학습지(Worksheet)'** 섹션입니다.

AI가 뱉어낸 차가운 JSON 데이터를, 우리가 학창 시절 풀던 그 익숙한 학습지의 형태로 렌더링해야 했습니다. 골드 이중선, 5개의 섹션 파티션 분할, 깔끔한 명조 계열 폰트 적용 등 모든 UI 요소는 **'종이 시험지'**의 감각을 재현하는 데 집중했습니다.

가장 많은 코드가 투입된 곳은 인터랙티브 퀴즈 영역이었습니다.
객관식(MCQ)은 클릭하는 즉시 정답 여부(그린/레드 컬러 + 아이콘)를 보여주고 하단에 해설을 전개(Reveal)합니다.
단답형(SA) 주관식은 처음에는 공란처럼 보였다가, 클릭 시 부드럽게 모범 답안이 드러나도록 구현했습니다.

_왜 정답을 한 번에 보여주지 않을까요?_
정답이 눈에 보이는 순간 사람의 사고는 멈춥니다. 잠깐이라도 스스로 고민할 '마찰'을 부여하는 것이 UX 관점에서도 학습 효율 관점에서도 중요했습니다.

## "여백의 미"가 가장 어려웠던 매칭 하이라이트

EP.3에서 다루었던 그 하이라이트 매칭.
100% 텍스트가 일치하는 건 백엔드의 승리지만, 프론트엔드에서는 이를 어떻게 보여줄지가 문제였습니다.

우리는 보통 컴퓨터 앞에서는 시원하게 큰 화면을 보고, 이동할 때는 폰의 작은 화면을 봅니다.
만약 모바일 화면에서 지문과 뜻풀이 팝업이 동시에 뜬다면 어떻게 될까요? 화면이 가득 차 숨이 막힐 겁니다.

그래서 **점진적 노출 (Progressive Disclosure)**을 핵심 원칙으로 삼았습니다.

1. 단어장 뜻풀이는 처음엔 `blur` 처리되어 있습니다. 호버(Hover)하거나 클릭할 때만 보이게 해서 '외우려는 노력'을 돕게 했습니다.
2. 지문에서 특정 구문을 탭하면, **데스크톱(정밀 제어 가능)에서는 Popover**가 뜨고, **모바일(터치 기반)에서는 하단에서 Drawer(BottomSheet)** 가 올라오도록 반응형 컴포넌트를 이원화했습니다.

한글 노출을 최대한 지연시키고 숨겨서 영어 그 자체와 먼저 부딪히게 만드는 디자인. 이게 teding이 그리는 UI의 핵심 철학입니다.

## 네이티브 인쇄의 마법: window.print() + @media print

학습 앱을 만들 때 많은 개발자가 'PDF 내보내기' 기능을 위해 `jsPDF`나 `html2canvas` 라이브러리를 도입합니다. 하지만 결과물은 종종 해상도가 깨지거나, 수백 KB가 넘는 외부 라이브러리 용량 때문에 초기 렌더링을 심각하게 늦추곤 합니다.

우리의 무기는 이미 브라우저에 다 준비되어 있습니다.

저는 **외부 라이브러리를 하나도 쓰지 않고** 오직 `window.print()`와 CSS의 `@media print` 쿼리만 사용했습니다.

```css
@media print {
    /* 네비게이션, 버튼, 진행률 바 등 UI 요소 싹 숨기기 */
    .hide-on-print {
        display: none !important;
    }

    /* 학습지 본문은 여백 없이 꽉 채우기 */
    .print-worksheet {
        padding: 0 !important;
        max-width: 100% !important;
    }

    /* 클릭해야 보이던 객관식 정답, 단어 뜻풀이 블러 등은 인쇄할 땐 전부 기본 노출 상태로 전환 */
    .reveal-blur {
        filter: none !important;
    }
}
```

이 간단한 CSS 몇 줄로:

- 성능 저하 0 (추가 라이브러리 0바이트)
- 벡터 방식의 무한 해상도 PDF (글씨가 절대 안 깨짐)
- 모바일(iOS/Android) 폰트 크기 최적화 자동 대응

개발의 본질은 "가장 단순한 방법으로 어썸한 결과를 내는 것"이라는 점을 이 인쇄 기능 구현에서 가장 크게 느꼈습니다.

## 식물 키우는 재미: SVG와 일 단위 스트릭(Streak) 연동

마지막 디테일은 대시보드 화면이었습니다.
연속 학습 일수(스트릭) 개념은 다른 앱에도 많았지만, 저는 여기에 조금 더 감성적인 피드백을 주고 싶었습니다.

그래서 **레트로 벡터 디자인 기반의 픽셀 식물 5단계 성장 시스템**을 도입했습니다.
7일, 14일, 21일, 30일 학습이 누적될 때마다 빈 화분에서 새싹이 자라나 화려한 꽃을 피우게 됩니다. 여기에 CSS `stroke-dasharray`를 활용해 SVG Ring이 현재 식물 단계까지 부드럽게 감싸면서 채워지도록 애니메이션을 넣었습니다.

이중 오프셋 날짜 계산(새벽 3시가 지나야 다음 날로 인정) 버그 때문에 `date-fns`와 눈물겨운 사투를 벌이기도 했지만, 이 작은 식물 하나가 주는 '내일 또 들어오고 싶은 동기'는 생각보다 컸습니다.
